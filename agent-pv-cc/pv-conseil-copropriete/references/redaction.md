# Rédaction — passer des notes au procès-verbal

Le PV est un document de gestion qui peut être relu par l'AG, un commissaire aux
comptes, un avocat ou un juge. Il doit être **factuel, neutre, complet et daté**.

## Ton et temps

- Français administratif belge, phrases courtes, voix active.
- **Présent de narration**, tenu d'un bout à l'autre : « Le syndic informe le conseil
  que… », « Le conseil prend acte… », « M. Dubois signale… ».
- Troisième personne. Jamais de « je », « on », « nous ».
- Pas d'adjectifs de jugement (« scandaleux », « catastrophique », « excellent ») : on
  décrit les faits et on attribue les opinions (« Mme Peeters estime que… »).
- Un désaccord se consigne sobrement : « M. X exprime son désaccord quant à… ;
  les autres membres présents ne partagent pas cet avis. »

## Verbes selon la nature de l'information

| nature | formulations |
|---|---|
| information du syndic | Le syndic informe / précise / rappelle que… |
| constat d'un membre | Mme X signale / constate / fait remarquer que… |
| prise de connaissance | Le conseil prend acte de… / prend connaissance de… |
| avis | Le conseil émet un avis favorable (défavorable) sur… / recommande… |
| demande au syndic | Le conseil demande au syndic de… (+ échéance si donnée) |
| décision sur délégation | En vertu de la délégation accordée par l'AG du [date], le conseil approuve… |
| report | Le point est reporté à la prochaine réunion, dans l'attente de… |

**Ne jamais écrire « le conseil décide »** sans délégation de l'AG mentionnée dans les
notes : le conseil n'a pas de pouvoir de décision propre (`structure-pv.md`).

## Transformer les notes

| note | PV |
|---|---|
| `asc en panne 22/10 → 24/10, carte HS, couvert omnium` | L'ascenseur a été immobilisé du 22 au 24 octobre 2026 en raison d'une carte de commande défectueuse. Le remplacement est couvert par le contrat omnium. |
| `3 devis toiture: meuse 8740 / ourthe 7980 sans nacelle / batiplus 9320 → CC préfère meuse` | Tableau des trois devis + « Le conseil recommande le devis de Toitures Meuse SRL. » |
| `lot 9 tjrs pas payé, relancer` | Le syndic informe que l'arriéré du lot 9 n'est pas régularisé. Le conseil demande au syndic de poursuivre le recouvrement. → action Syndic |
| `marc regarde bornes recharge` | M. Dubois se propose d'étudier l'installation de bornes de recharge. → action M. Dubois |
| `PV précédent ok` | Le procès-verbal de la réunion du [date] est approuvé à l'unanimité des membres présents. |

- Chaque note doit atterrir quelque part ; une note incompréhensible → question.
- Une même idée répétée dans les notes → une seule mention, au bon point.
- Une échéance relative (« dans 15 jours », « avant l'AG ») → date absolue si la date
  de la réunion le permet, sinon garder la formulation.
- Un « ok » ou « vu » sans précision → « Le conseil prend acte. », pas « approuve ».

## Forme des données

- Dates : « 5 novembre 2026 » dans le texte ; `JJ/MM/AAAA` dans les tableaux (le
  générateur formate les dates ISO `2026-11-05`).
- Heures : `18h00` (le générateur formate `18:00`).
- Montants : `8.740,00 €` (point des milliers, virgule décimale), avec TVAC/HTVA si
  connu. Les colonnes de montants sont alignées à droite automatiquement.
- Personnes : civilité + prénom + nom à la première mention (« M. Marc Dubois »),
  ensuite civilité + nom (« M. Dubois »). Les fournisseurs : raison sociale exacte.
- Lots : « lot 9 » ou « appartement 4B » selon l'usage de l'immeuble ; rester constant.

## Données personnelles

- Arriérés, litiges, mises en demeure : désigner le **lot**, pas le copropriétaire.
- Pas de santé, situation familiale, conflit de voisinage nominatif détaillé : résumer
  (« un différend de voisinage est signalé au 3e étage ; le syndic prendra contact
  avec les occupants concernés »).
- Les membres du conseil et les intervenants professionnels sont nommés normalement.
